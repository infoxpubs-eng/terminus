# 🚇 MétroQuiz — Attrape la bonne réponse

Jeu mobile de dextérité et culture générale, pensé pour les trajets en métro.

Une question s'affiche, les réponses tombent comme des voyageurs sur le quai :
touche la bonne réponse au vol (ou glisse ta rame 🚃 pour l'attraper) et évite les mauvaises.

## Règles

- 🎯 Tu démarres avec 100 points
- 👆 Touche directement la bonne réponse quand elle tombe, ou glisse ta rame
- ⚡ Plus tu réponds vite, plus tu gagnes de points (bonus « Éclair ») ; les combos multiplient les gains
- ❌ Mauvaise réponse : −75 points, autant d'essais que tu veux
- 🛑 Si le score passe sous zéro, c'est Terminus !

10 catégories : Histoire, Géographie, Sciences, Cinéma, Musique, Littérature, Sport, Badminton, Gastronomie, Langue française.

## Jouer

Fichier unique, aucune installation (React et Tailwind via CDN), record sauvegardé dans le navigateur.

- En ligne : https://infoxpubs-eng.github.io/terminus/
- En local : ouvrir `index.html`
